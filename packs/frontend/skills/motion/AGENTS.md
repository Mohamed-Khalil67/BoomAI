# Motion skills

Animation, from small transitions to scroll-driven scenes.

| Skill | Use it for |
|---|---|
| [`advanced-animations`](advanced-animations/SKILL.md) | Builds complex, high-end animations - scroll-driven effects, parallax, pinned sections, sequenced timelines, FLIP and shared-element transitions, SVG path and morph effects, text splitting, canvas and WebGL. |
| [`web-animations`](web-animations/SKILL.md) | Adds and fixes UI animations and micro-interactions using CSS transitions, keyframes, the Web Animations API and View Transitions. |

To add a skill here: create `<name>/SKILL.md` with `name` and `description` frontmatter and add a row above. The installer finds it on its own.
