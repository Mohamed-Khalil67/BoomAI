# Design to code skills

Turning an existing site or screenshot into code. Figma frames go through the Figma MCP.

| Skill | Use it for |
|---|---|
| [`replicate-website`](replicate-website/SKILL.md) | Rebuilds the look and layout of an existing website or screenshot as clean code in the current project's framework, then compares it against the original until it matches. |

To add a skill here: create `<name>/SKILL.md` with `name` and `description` frontmatter and add a row above. The installer finds it on its own.
