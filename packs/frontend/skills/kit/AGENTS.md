# Kit skills

Upstream Angular skills and the owner's habits.

| Skill | Use it for |
|---|---|
| [`my-coding-habits`](my-coding-habits/SKILL.md) | The owner's personal Angular and TypeScript coding habits and house rules - standalone components, signals, native control flow, inject(), signal forms, accessibility minimums and what never to use. |
| [`refresh-framework-skills`](refresh-framework-skills/SKILL.md) | Installs or updates the latest official framework skills (Angular, plus the optional UI UX Pro Max design skill) into the current project's .claude/skills. |

To add a skill here: create `<name>/SKILL.md` with `name` and `description` frontmatter and add a row above. The installer finds it on its own.
