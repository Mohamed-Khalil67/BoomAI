# Quality skills

Read-only reviews: accessibility and performance.

| Skill | Use it for |
|---|---|
| [`accessibility-review`](accessibility-review/SKILL.md) | Reviews Angular UI changes or a page for WCAG AA accessibility problems - semantics, accessible names, labels, keyboard use, focus, contrast, target size, reduced motion, live regions and ARIA misuse - and reports findings without editing files. Use after UI work, or when the user says check accessibility, a11y review, audit this page, WCAG, or is this accessible. |
| [`performance-audit`](performance-audit/SKILL.md) | Audits an Angular app's performance - bundle size, lazy loading and @defer, change detection, images and fonts, layout shift, Core Web Vitals - measuring before recommending, and reports prioritized findings without editing files. |

To add a skill here: create `<name>/SKILL.md` with `name` and `description` frontmatter and add a row above. The installer finds it on its own.
