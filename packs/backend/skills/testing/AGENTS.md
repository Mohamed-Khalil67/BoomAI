# Testing skills

Unit and e2e tests for NestJS.

| Skill | Use it for |
|---|---|
| [`nest-testing`](nest-testing/SKILL.md) | Writes and fixes NestJS tests - unit tests with Test.createTestingModule and overrideProvider, e2e tests with supertest against a real app, a real Postgres through Testcontainers, test data factories, and testing guards and validation. |

To add a skill here: create `<name>/SKILL.md` with `name` and `description` frontmatter and add a row above. The installer finds it on its own.
