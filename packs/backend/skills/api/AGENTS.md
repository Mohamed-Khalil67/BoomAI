# API skills

The HTTP contract: DTOs, errors, pagination, versioning, OpenAPI.

| Skill | Use it for |
|---|---|
| [`api-contract`](api-contract/SKILL.md) | Designs and reviews the HTTP contract of a NestJS API - resource naming, request and response DTOs, one error format (RFC 9457 problem details), pagination, idempotency, versioning and OpenAPI docs. |

To add a skill here: create `<name>/SKILL.md` with `name` and `description` frontmatter and add a row above. The installer finds it on its own.
