# NestJS skills

NestJS app wiring and architecture.

| Skill | Use it for |
|---|---|
| [`nestjs-best-practices`](nestjs-best-practices/SKILL.md) | NestJS best practices and architecture patterns for building production-ready applications. (from Kadajett, see `vendor.json`) |
| [`nestjs-core`](nestjs-core/SKILL.md) | Sets up and fixes the core of a NestJS 11 or 12 app - bootstrap in main.ts, global validation, typed and validated configuration, security middleware, rate limiting, graceful shutdown, Express 5 routes, and CommonJS vs ESM imports. |

To add a skill here: create `<name>/SKILL.md` with `name` and `description` frontmatter and add a row above. The installer finds it on its own.
