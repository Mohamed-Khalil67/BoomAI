# TypeScript skills

Type safety for Angular code.

| Skill | Use it for |
|---|---|
| [`typescript-safety`](typescript-safety/SKILL.md) | Strict compiler settings, no `any`, typed inputs, outputs, forms and routes, safe API data, a typecheck gate. |

## Adding a skill here

1. Create `<name>/SKILL.md` in this folder with `name` and `description` frontmatter.
2. Add a row to the table above.
3. Follow the rest of the checklist in [docs/MAINTAINING.md](../../docs/MAINTAINING.md#checklist-adding-a-skill).
