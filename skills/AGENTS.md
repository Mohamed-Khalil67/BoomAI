# Skills map

Skills are grouped by category. Each category folder has an `AGENTS.md` that lists its skills and links to each `SKILL.md`.

| Category | Index | Skills |
|---|---|---|
| Angular | [angular/AGENTS.md](angular/AGENTS.md) | `angular-patterns` |
| TypeScript | [typescript/AGENTS.md](typescript/AGENTS.md) | `typescript-safety` |
| Styling | [styling/AGENTS.md](styling/AGENTS.md) | `css-styling` |
| Motion | [motion/AGENTS.md](motion/AGENTS.md) | `web-animations`, `advanced-animations` |
| Design to code | [design-to-code/AGENTS.md](design-to-code/AGENTS.md) | `replicate-website` |
| Quality | [quality/AGENTS.md](quality/AGENTS.md) | none yet |
| Kit | [kit/AGENTS.md](kit/AGENTS.md) | `setup`, `refresh-framework-skills`, `my-coding-habits` |

Claude Code finds plugin skills only one folder below each path listed in `"skills"` in `.claude-plugin/plugin.json`. A new category folder must be added to that list, or its skills will not load.
