# Motion skills

Animation, from small transitions to scroll-driven scenes.

| Skill | Use it for |
|---|---|
| [`web-animations`](web-animations/SKILL.md) | Transitions, keyframes, micro-interactions, View Transitions, reduced motion. |
| [`advanced-animations`](advanced-animations/SKILL.md) | Scroll-driven effects, timelines, FLIP, SVG morphs, canvas and WebGL. |

Start with `web-animations`; move to `advanced-animations` only when the effect needs scroll, timelines or canvas.

## Adding a skill here

1. Create `<name>/SKILL.md` in this folder with `name` and `description` frontmatter.
2. Add a row to the table above.
3. Follow the rest of the checklist in [docs/MAINTAINING.md](../../docs/MAINTAINING.md#checklist-adding-a-skill).
