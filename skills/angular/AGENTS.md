# Angular skills

Angular building blocks: components, signals, async state, RxJS and template patterns.

| Skill | Use it for |
|---|---|
| [`angular-patterns`](angular-patterns/SKILL.md) | AsyncState unions, `@let` narrowing, declarative RxJS streams, signals with `ngModel`, `ng serve` port collisions on Windows. |

The official `angular-developer` and `angular-new-app` skills are not stored here; `kit/refresh-framework-skills` fetches them into each project.

## Adding a skill here

1. Create `<name>/SKILL.md` in this folder with `name` and `description` frontmatter.
2. Add a row to the table above.
3. Follow the rest of the checklist in [docs/MAINTAINING.md](../../docs/MAINTAINING.md#checklist-adding-a-skill).
