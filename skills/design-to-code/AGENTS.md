# Design to code skills

Turning an existing design, site or screenshot into code.

| Skill | Use it for |
|---|---|
| [`replicate-website`](replicate-website/SKILL.md) | Rebuild a site's look from a URL or screenshot, then compare against the original until it matches. |

Figma frames are read through the Figma MCP; this folder covers non-Figma sources.

## Adding a skill here

1. Create `<name>/SKILL.md` in this folder with `name` and `description` frontmatter.
2. Add a row to the table above.
3. Follow the rest of the checklist in [docs/MAINTAINING.md](../../docs/MAINTAINING.md#checklist-adding-a-skill).
