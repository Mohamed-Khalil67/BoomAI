# Kit skills

Skills about the kit itself: setup, upstream skill updates, the owner's habits.

| Skill | Use it for |
|---|---|
| [`setup`](setup/SKILL.md) | Guided first-time setup in an Angular project. |
| [`refresh-framework-skills`](refresh-framework-skills/SKILL.md) | Fetch or update the official Angular skills (and optional UI UX Pro Max) into the project. |
| [`my-coding-habits`](my-coding-habits/SKILL.md) | The owner's Angular and TypeScript habits; points at `docs/agents/` instead of repeating rules. |

## Adding a skill here

1. Create `<name>/SKILL.md` in this folder with `name` and `description` frontmatter.
2. Add a row to the table above.
3. Follow the rest of the checklist in [docs/MAINTAINING.md](../../docs/MAINTAINING.md#checklist-adding-a-skill).
